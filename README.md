# Crypto-Pro-AI MVP

English-language web interface for crypto market analysis and a local Project Chat prototype.

## Included

- Binance public market analysis
- RSI, EMA, ATR, support and resistance
- BUY / SELL / WAIT signal
- Entry, stop loss and take profit plan
- English UI
- AI Project Chat prototype
- Chat history stored in browser localStorage

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Important

The current Project Chat uses local prototype responses. A secure server-side AI integration and database-backed project memory will be added in the next phase.

This application is educational software and not financial advice.
